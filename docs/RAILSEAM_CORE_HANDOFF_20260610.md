# Rail-seam 핵심 단일순환 — 증명 핸드오프 (2026-06-10)

저자 직접 증명용 패키지. 남은 것은 정확히 아래 §1의 명제(들)이고, §4 형태의
증명이 주어지면 형식화는 기계적으로 이어받는다.

## 1. 증명할 것 (Lean 시그니처, 모듈 2 `D3EvenRailSchedule` 기준)

```
IsSingleCycleMap (fun w : (ZMod m)² => rho c w + u_c)
```
- `rho c` = wild layer의 색-c deviation: 2m-zigzag(닫힌 형태 `seamPoint c`,
  모듈 1)에서 한 칸 전진, 그 외 항등.
- 드리프트(증명 완료, 모듈 2): `3∤m`: u = ((1,1),(m−2,1),(1,m−2));
  `3∣m`: u = ((m−4,1),(3,m−4),(1,3)). 케이스 × 3색 = 6명제.
- 이것만 닫히면: `railCycleData`(모듈 2) → `D3EvenCycleDataFamily` →
  per-color realization(rank 수송) → **H1b 닫힘(홀 3→2)**.

## 2. 권장 엔진 (이미 형식화돼 있음)

`TerminalA2IntervalSplice.single_cycle_of_interval_splice`:
label 집합 L 위 σ 단일순환 + 구간 순회 `F^[len l](head l) = head (σ l)` +
커버리지 ⟹ F 단일순환. H1a를 닫은 그 보조정리.

본 사례 인스턴스: G(w) = rho(w) + u; 비활성점에서 G = +u 평행이동, seam 점
`seamPoint k`에서 G = `seamPoint(k+1) + u`. 따라서
- `head k := seamPoint(k+1) + u`,
- `σ(k) :=` head k에서 +u-ray를 따라 처음 만나는 active 점의 rank,
- `len k := (그 first-hit ray 길이) + 1`.

증명 의무 분해: (a) ray 중간점 비활성, (b) first-hit 닫힌 형태,
(c) σ 단일 2m-순환, (d) 커버리지(모든 ⟨u⟩-coset이 seam과 만남 + 점별 소속
구간), (e) Σ len = m² (검산용; 커버리지 증명 방식에 따라 불필요할 수 있음).

세그먼트 구조 (c=0, m 일반, 표에서 읽힌 후보 — 검증 필요):
- k ∈ [0, m/2−3]: σ(k) = k + m/2 + 1, len = m/2
- k = m/2−2: σ = m/2−1?? (m=14: k=5→6) , len = m
- k ∈ [m/2−1, m−3]: σ(k) = 2k+3, len = m−1−k (감소열)
- k ∈ [m−2, m−1]: σ = k+14−... (m=14: 12→26, 13→27: σ = k+m), len = 1
- k = m: σ = 0, len = 1
- k 홀수 ∈ [m+1, 2m−5]: σ = k+1, len = m
- k 짝수 ∈ [m+2, 2m−4]: σ = (k−m)/1...: (m=14: 16→1,18→2,20→3: σ = (k−m)/2... 16→1: (16−14)/2=1 ✓ 18→2 ✓), len = (k−m)/2+1
- k = 2m−3, 2m−2: σ = k−m+1? (m=14: 25→13? 표는 25번째... 인덱스 주의), len = m−1
- k = 2m−1: σ = m/2, len = m/2
(경계 인덱스는 표와 직접 대조해 확정할 것 — 위는 골격.)

**대칭 (중요)**: len 배열 기준 c=1 = c=0의 rank-회전(−3), c=2 = c=0의
rank-회전(+5) (m=8 확인; m=10,14도 동일 패턴). wild layer의 색 순환
(0→1→2)이 seam을 평행이동+회전으로 보내는 대칭이 있는 것으로 보이며,
형식화되면 **한 색의 핵심 증명 + 대칭 수송으로 세 색을 모두** 덮는다.
(u_c들도 이 대칭으로 엮이는지 확인 필요: (1,1)→(m−2,1)→(1,m−2)…)

## 4. 어떤 형태의 증명이면 기계화 가능한가

다음 중 아무 형태나 좋다 (위에서 아래로 갈수록 기계화가 빠름):

1. **σ/len 닫힌 형태표 + 산술 항등식들**: 각 세그먼트에서 (a) ray 비활성
   부등식, (b) first-hit 등식 `seamPoint(k+1) + len(k)·u = seamPoint(σ k)`...
   (정확히는 `+ (len k − 1)·u`), (c) σ의 순환 순서를 주는 rank 재배열
   (hdesc와 동일 패턴: `σRank : Fin 2m ≃ ZMod 2m`, σ = +1 켤레).
2. **coset-단면 논증**: φ(u)가 unit인 좌표 φ로 ⟨u⟩-coset을 자르고, coset
   index 동역학(= ZMod m 평행이동 + seam 교차 carry)을 UnitCarry로 닫는
   서술 — D2 증명의 한 단계 위 버전. carry 표만 명시되면 기계화 가능.
3. **대칭 + 한 색**: 색 순환 대칭의 명시적 동형(평행이동 τ와 좌표 회전 σ₃로
   `rho_{c+1} = g ∘ rho_c ∘ g⁻¹`, `u_{c+1} = g(u_c)` 형태) + 색 0 하나의
   1 또는 2.

수치 검산은 `scripts/search_d3_even_dir.py` + 본 문서 §3 추출 스니펫
(세션 기록)으로 즉시 가능하다. 어떤 m에서든 σ/len 표를 뽑아 드릴 수 있다.
