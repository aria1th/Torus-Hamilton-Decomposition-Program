### 1.2 The center-change `sectionEquiv` (constraint-1 deliverable)

Work at layer `t = 0`.  The physical height-0 vertex has `Σ_{ω∈Ω} x_ω = 0`; the
paper chart stores all `x_ω` with `ω ≠ τ₀`; the Lean chart stores all `x_ω` with
`ω ≠ p_{b-1}⁻`.  The explicit linear equivalence

```
Φ : (LaneZ b m) × (RootState 2 m) × (LaneZ b m) ≃ RootState (2*b) m   -- (y,q,z) ↦ w
w 0        := −(q 0 + q 1 + Σ_j y j + Σ_j z j)      -- τ₀ slot
w 1 := q 0,  w 2 := q 1                              -- τ₁, τ₂
w (3+2j) := y j                  (j ≤ b-2)           -- plus lanes
w (4+2j) := z j                  (j ≤ b-3)           -- stored minus lanes
-- z (b-2) is the hidden coordinate: recovered as −Σ_{i<2b} w i
```

Inverse: `q i = w (i+1)`, `y j = w (3+2j)`, `z j = w (4+2j)` for `j ≤ b-3`,
`z (b-2) = −Σ_i w i`.  Triangular, hence an explicit `AddEquiv`; `b = 4` check:
`w = (τ₀-slack, q₁, q₂, y₀, z₀, y₁, z₁, y₂)`, hidden `z₂`.

**Displacement dictionary.**  Pulling one physical step back through `Φ` gives, in
`E`-coordinates,

| direction read | `Φ⁻¹`-displacement |
|---|---|
| `τ₀` | `− e_{z_{b-2}}` |
| `τ_i` (i=1,2) | `e_{q_i} − e_{z_{b-2}}` |
| `p_{j+1}⁺` | `e_{y_j} − e_{z_{b-2}}` |
| `p_{j+1}⁻`, j ≤ b−3 | `e_{z_j} − e_{z_{b-2}}` |
| `p_{b-1}⁻` (= Lean `Fin.last`) | `0` |

i.e. paper-template displacement (`δ_{τ₀}=0`, `δ_ω = e_ω`) **minus a uniform
`e_{z_{b-2}}` artifact per step**.  Over one period (m layers, m steps) the artifact
sums to `m·e_{z_{b-2}} = 0`:

> **Lemma (Φ-period dictionary).**  For any m-step word, the per-period
> `E`-displacement through `Φ` equals the paper-template displacement
> (`δ_{τ₀} = 0`, `δ_ω = e_ω` otherwise).

So all per-period budget arithmetic below is done in paper coordinates; it is
exactly the Lean arithmetic after `Φ`.

**Key cylinder fact (used throughout §3–§4).**  An `E`-cylinder pinning
`(q, y, z_0..z_{ν-1})` and freeing `z_ν..z_{b-2}` maps under `Φ` to an honest
**coordinate cylinder in `w` with `w 0` free** (because the hidden `z_{b-2}` is
free and appears only in `w 0`).  Hence E5-invariance under any
`d = stepVec β − stepVec α` with `α ∈ {τ₀, Fin.last}` and `β` a free lane holds
*literally*.  This is the only systematic family of RF2-legal localized supports.

## 3. Displacement budget check (deliverable 1)

### 3.1 The budget rules

For a row schedule, color `c`'s period word is exactly `m` reads; each read is one
direction; per layer **exactly one of the `2b+1` colors gets each direction**, in
particular exactly one color per layer gets the zero-displacement read.  Hence:

* (B1, per point) the per-period displacement of color `c` at every state has a
  nonnegative integer lift of mass `≤ m` (mass = Σ of canonical representatives;
  padding only by zero-reads actually granted to `c`).
* (B2, Latin total) summing `mass = m − (#zero-reads)` over all colors and all
  states: `Σ_{c,x} mass_c(x) = 2b·m^{2b+1}` exactly (per layer, per state: `2b`
  unit steps + 1 zero among the `2b+1` colors).

Under a **linear** sectionEquiv these rules transport verbatim (linearity preserves
displacement classes); this is the H2-blocker/H1b test.

### 3.2 Intended per-class displacement classes (paper ledger)

Paper models (endpoint_successor.tex: ledger lines 25–40; lem:endpoint-active-core
lines 66–111; b=4 trace endpoint_b4_chart.tex lines 26–42):

| class | intended return | per-period displacement at state `x` |
|---|---|---|
| `t_i` | `(T_i q, P_i^{1_{q=q_i}} y, z)` | `q ≠ q_i`: `Δ_{T_i}(q) ⊕ 0`; **`q = q_i`: `Δ_{T_i}(q_i) ⊕ (P_i y − y)`** |
| `d_{i+1}` | `(T_i q, P_i^{1_{q≠q_i}} y, z)` | **`q ≠ q_i`: `Δ_{T_i}(q) ⊕ (P_i y − y)`**; `q = q_i`: `Δ_{T_i}(q_i) ⊕ 0` |
| `μ_j` | completion tower / reset | one-point carries (small) |

with `T_i` = D3 return of color `i` (mass of `Δ_{T_i}(q)` = `m − z_i(q)`,
`z_i(q)` = zero-reads of D3 color `i` along the period trajectory of `q`) and
`P_i` = parent return on `Y` (single `m^{b-1}`-cycle; mass of `P_i y − y` =
`m − (parent zero-reads)` if realized by a parent word).

### 3.3 Verdict per class

* `t_i`, **firing fiber `q = q_i`** (and dually `d_{i+1}` on the complement, which
  is worse — it fires on `m²−1` of `m²` fibers): required mass
  `= mass(Δ_{T_i}(q_i)) + mass(P_i y − y)`.  Both summands are full m-step words
  of *independent* schedules: generically `≈ 2m/3 + (b-1)m/b > m`.  **B1
  violated.**  With the *arbitrary* D3 input demanded by constraint 2, even the
  best case is not controllable: `z_i(q_i) = 0` is possible (a Latin D3 schedule
  may give color `i` no zero-reads on a given trajectory), so even a crafted
  `P` with unit increments (Gray-code cycle, increments `±e_j`, masses `1`/`m−1`)
  exceeds the budget at the firing fiber (`m + 1 > m` resp. `(m−1) + mass(Δq) > m`
  whenever `mass(Δq) ≥ 2`).
* `b = 4, m = 4` anchor: `Q = (ℤ/4)²` (16 states), `Y = (ℤ/4)³` (64), period 4
  steps.  D3 per-trajectory masses average `8/3 ≈ 2.67`; extracted-parent
  `P − id` at a typical point has mass `≈ 3·(4−1)/2 = 4.5`; firing requirement
  `≈ 7 > 4`.  For `d_{i+1}` this over-budget displacement is required at `15/16`
  of all states — B2 is violated wholesale: model-side
  `Σ mass ≈ m^{2b}·(15/16)·7·…` exceeds the Latin total `2b·m^{2b+1}/(2b+1)`-share
  by a constant factor.
* Chart freedom does **not** rescue this tamely: per-color cyclicity (RF3) is
  conjugation-invariant, so one may seek `returnMap c = e_c ∘ model_c ∘ e_c⁻¹`
  with non-linear `e_c` — but then `e_c` is exactly the **wild run-collapse
  reindexing** of `H2_REALIZATION_BLOCKER_20260605.md` §4(B) /
  `H1B_REALIZATION_OBSTRUCTION_20260609.md` §3, an unresolved *design* problem
  (solved for H2 only by a finite `native_decide` witness, unavailable here since
  `(b,m)` is parametric).
* μ-class one-point carries are individually budget-fine (mass ≤ 1 each), but
  their *realization* hits Wall 2 (§4.2), and the μ-colors' `q`-attachment hits
  Wall 3 (§4.3).

**Conclusion: obstructed.**  The literal ledger models are not the period-maps of
any RF1-legal row schedule under any linear sectionEquiv; the non-linear escape is
the same open wild-`e` problem as H1b.  Note this is *consistent with the paper*:
the paper computes returns at the template level and defers realization to
lem:endpoint-local-row-realization, whose two-color rows are unproblematic but
whose completion rows hide Wall 2 — exactly the kind of gap already catalogued for
`lem:terminal-latin` (H1b) and the D5(4) §11 substitutions (H2).

## 4. The three walls (precise statements, recordable as negative theorems)

### 4.1 Wall 1 — firing-fiber budget (above)

Statement to record (optional Lean negative theorem, b=4, m=4, finite): *no
function `dir : ZMod 4 → RootState 8 4 → Perm (Fin 9)` whose `rowSchedule` return
of color 0 equals `Φ ∘ (T₀ ⊗ P^{1_{q=q₀}} ⊗ id) ∘ Φ⁻¹` exists* — provable by the
per-point step-mass invariant (each return value differs from the argument by an
m-step sum).  Parametric version: for every linear chart, B1 fails on the firing
fiber for some input data — keep as documented analysis, not formalized.

### 4.2 Wall 2 — localized full-row `C_h` substitutions violate RF2 (provable)

For a layer whose row is `ρ` off `U` and `C_h ∘ ρ`-shaped on `U` (both reads
constant for a given color), the color-`c` layer map is two-valued, and
bijectivity is *equivalent* to `U + d_c = U`, `d_c = stepVec(σ c) − stepVec(ρ c)`
(same argument as `EndpointRowSchedule.cylinderShift_bijective`; the equivalence
direction is elementary).  For the full cyclic row `C_h` the difference vectors
over all colors include two unit vectors (`stepVec` of the slots shifted into/out
of the zero slot `Fin.last`) plus the chain `e_{k+h} − e_k`; **the subgroup they
generate is all of `(ℤ/m)^{2b}`** (for `gcd(h, 2b+1) = 1`).  Hence the only
`U` invariant for *every* color is `∅` or everything:

> **Negative lemma (E6-W2).**  A `C_h` row substituted on a proper nonempty
> subset `U ⊂ RootState (2b) m` over any constant base row fails
> `layerBijective` for at least one color.  (`b = 4, m = 4`: `decide`-able;
> parametric: the lattice-generation argument, mechanical.)

Consequence: the paper's "cyclic completion row over the singleton completion
site `c_ν`" (def:cyclic-completion-rows lines 114–123, def:lifted-completion-fiber
lines 265–281, lem:completion-fiber-bijectivity lines 283–298) admits **no
two-valued row realization**; `lem:completion-fiber-bijectivity`'s image-disjointness
argument does not survive the exact criterion.  Constant `C_h` layers
(`E5 completionDesc`, `U = everything`) are RF2-fine but contribute only constant
(hence vanishing, `m·const = 0`) carries — they cannot produce the ledger's
one-point carries.  The one-point carries must instead come from **two-color
swaps** with the §1.2 cylinder family — which is possible for `(α, β)` pairs with
`α ∈ {τ₀-read, Fin.last-read}` but is then constrained by Wall 3.

### 4.3 Wall 3 — partner/donation deadlock for lane colors (structural)

Every color's return must move the `q`-block.  Lane colors (`d_j`, `μ_j`) never
read `τ₁/τ₂` generically, so they must *gain* `q`-reads via swaps with terminal
colors.  Bookkeeping forced by the additive-skew machinery (carry at level θ must
be a function of the strictly-lower tower coordinates; supports must satisfy the
E5 invariance):

* the **donor** terminal color's D3 base gets a point cut whose firing condition
  involves the support's lane pins — *higher* coordinates in the donor's tower ⇒
  the donor's base is no longer autonomous (not an additive skew product);
* removing the lane pins makes the donee's `q`-carry depend on `q` itself
  (self-referential attachment, illegal);
* same-cell 3-cycle reads (donor → zero, zero-owner → donor's letter, lane → …)
  violate the exact two-valued criterion of §4.2 along the `(α, τ₀)` line.

Escape routes exist but leave the additive machinery: the donor's corrected base
becomes a **permutation-valued (word-skew) monodromy** problem, with a parity
side-condition (each line-cut is an odd permutation; `m²`-cycles are odd; the
number of cuts per donor must be odd, while the total number of donations
`2·(b−1)·2` is even — so paired dummy corrections are needed).  None of this is
covered by `UnitCarry`/`CompletionTower`/E5; it would be a new calculus
(`WordSkew`/`Shared.Monodromy` extensions) co-designed with the wild-`e` of Wall 1.
This is exactly the realization problem, restated.

## 5. What is provable now (deliverable 3, sound parts)

### 5.1 E6a — parent cycle extraction (closes the "P : Y → Y, m-power period" question)

`FinalMarkedPayload b m` (`FinalTargetPredicateBridge.lean:26`) is a `Prop`:
`target : Shared.TorusHamiltonDecomposition b m` (= `Nonempty (CayleyDecomposition b m)`,
`Shared/TorusCayley.lean:487`) plus PUnit-fillable evidence.  From
`D : CayleyDecomposition b m` and any parent color `c`:

* `g := Shared.cayleyColorStep D.colorDir c : V → V`, `V = TorusVertex b m`;
  `D.colorHamiltonian c : IsSingleCycleMap g`; every step adds `torusBasis`, so
  the height `S x = Σ_i x i` satisfies `S (g x) = S x + 1`.
* `Sec := {x : V // S x = 0}`; `Sec ≃ LaneZ b m` by dropping the last coordinate
  (mechanical chart, fill `x_{b-1} = −Σ`); `Nat.card Sec = m^{b-1}`.
* `P : Sec → Sec := fun x => ⟨g^[m] x, …⟩` (height `+m = 0` mod m).

> **Theorem (E6a-1).** `IsSingleCycleMap P`.
> Proof (fully mechanical, no rank arithmetic): bijectivity from `g` bijective;
> transitivity: for `x y : Sec` pick `n` with `g^[n] x = y` (g single cycle);
> heights give `(n : ZMod m) = 0`, so `n = k*m` and `P^[k] x = y`.

> **Corollary (E6a-2).** `∃ rank : Sec ≃ ZMod (m^(b-1)), ∀ x, rank (P x) = rank x + 1`
> — by `CompletionTower.rankEquiv_of_singleCycle P (E6a-1) (card)`.
> This is precisely "where `rankEquiv_of_singleCycle` normalizes the parent
> period".  `NeZero (m^(b-1))` from `4 ≤ m`.

What is **not** extractable: the parent's *word* (its layer schedule).  Only the
abstract cycle `P` and its rank are available; this suffices for E6b but is
exactly what makes Wall 1 unliftable (the child cannot replay a word the parent
payload does not carry).

### 5.2 E6b — abstract active core (terminal + auxiliary classes)

### 5.4 E6b — μ-class and reset-class seed models
